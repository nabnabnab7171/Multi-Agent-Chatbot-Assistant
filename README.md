# Personal AI Agent Toolkit

Six reusable specialist agent instructions for study, master's research, careers, finance, document analysis and project building.

## Getting started
1. Open an agent file in the agents folder.
2. Copy its instructions plus AGENTS.md into a ChatGPT conversation or project instructions, or ask a coding agent that reads AGENTS.md to use the matching specialist.
3. Provide your task and, when needed, supporting files. Keep sensitive documents outside this public repository.

## Agents
- [Study Tutor](agents/study-tutor.md)
- [Research Analyst](agents/research-analyst.md)
- [Career Agent](agents/career-agent.md)
- [Finance Analyst](agents/finance-analyst.md)
- [Document Analyst](agents/document-analyst.md)
- [Project Builder](agents/project-builder.md)

## Important limitation
This repository provides agent prompts and a convention for coding assistants. GitHub alone does not execute agents, and connecting GitHub to ChatGPT does not auto-install these prompts as native ChatGPT agents. Running autonomous orchestration needs an additional app or runtime.

## Safety
Do not commit credentials, personal academic records, financial records, identity documents, or confidential application material. Verify all external claims and request confirmation before sending or publishing anything.
